# OOPLab4 — лабораторна робота 3.4, варіант 4

## Відповідність завданню

- Масив `char` сортується за спаданням. Виклик сортування демонструється через власний делегат двома способами: анонімним методом і лямбда-виразом.
- `BoundedCharQueue` моделює чергу обмеженої місткості: додавання в кінець, видалення з початку та очищення.
- Коли черга повна і викликається `TryEnqueue`, джерело `BoundedCharQueue` генерує подію `Overflowed`. Невдале додавання повертає `false`, а обробник повідомляє користувачу про місткість, кількість елементів і відхилений символ.
- Аргументи події винесені в `QueueOverflowEventArgs`. Метод `OnQueueOverflow(object? sender, QueueOverflowEventArgs eventArgs)` розміщений в окремому класі-обробнику і відповідає шаблону стандартних подій .NET.

## Структура

- `Program.cs` — головне меню.
- `CharacterSortDemo.cs` — власний делегат, анонімний метод, лямбда-вираз і сортування.
- `Events/BoundedCharQueue.cs` — обмежена черга та джерело події.
- `Events/QueueOverflowEventArgs.cs` — дані події.
- `Events/QueueEventHandler.cs` — клас із методом-обробником.
- `Events/QueueDemo.cs` — консольна взаємодія, підписка та відписка від події.

## Запуск

Потрібен .NET SDK 8.0 або новіший, який підтримує `net8.0`.

```powershell
cd D:\Programs\OOPLab4
dotnet run
```

У меню виберіть `1`, щоб увести рядок і побачити його символи в порядку спадання. Виберіть `2`, щоб створити чергу заданої місткості; додавання понад її місткість викличе обробник події. Порожній рядок для сортування допускається, а місткість черги має бути додатним цілим числом.

## Пояснення до контрольних питань

1. **Делегат** — типобезпечне посилання на метод або групу методів із певним списком параметрів і типом результату. У роботі `CharacterArraySorter` посилається на метод, що приймає `char[]` і повертає `char[]`.
2. **Опис і виклик:** `delegate char[] CharacterArraySorter(char[] characters);` Далі змінна делегата отримує сумісний метод, а виклик `sorter(array)` виконує його.
3. Делегат має типізований список виклику (invocation list) методів та дані, потрібні для виклику. Для методу екземпляра також зберігається цільовий об’єкт; для статичного методу цільового об’єкта немає.
4. Контроль типів забезпечується сигнатурою делегата під час компіляції: метод має мати сумісні параметри та результат.
5. Делегат у .NET є об’єктом класу, похідного від `System.MulticastDelegate` (а той — від `System.Delegate`). Усередині він зберігає посилання на метод, його ціль (коли метод екземпляра) та список виклику. Виклик делегата виконує методи зі списку. Опис делегата компілятор перетворює на клас делегата.
6. **Анонімний метод** — тіло методу без окремого імені, яке можна прив’язати до сумісного делегата. У прикладі це `delegate (char[] values) { ... }`.
7. **Лямбда-вираз** — короткий запис анонімної функції: параметри зліва від `=>`, тіло справа. Наприклад, `values => SortDescending(values)`. Тип параметра визначається делегатом.
8. Побічні ефекти можуть виникнути, коли анонімний метод чи лямбда захоплює змінну із зовнішньої області. Наприклад, `int count = 0; Action increment = () => count++;` — виклик змінює `count`, і результат залежить від часу виклику. Захоплена змінна може жити довше за метод, у якому її створено; спільний доступ до змінної в асинхронному чи багатопотоковому коді також потребує уваги. У сортувальній демонстрації зовнішні змінні не захоплюються.
9. Подію оголошують у класі-джерелі, наприклад: `public event EventHandler<QueueOverflowEventArgs>? Overflowed;`. Параметр `EventHandler<TEventArgs>` визначає сумісну форму обробника.
10. Джерело події виявляє умову та викликає захищений метод генерації; той викликає делегат події, якщо є підписники. Тут переповнення перевіряється перед додаванням, а `OnOverflowed` передає `this` та об’єкт аргументів підписникам.
11. Підписка виконується оператором `+=`, відписка — `-=` з тим самим екземпляром обробника. Після відписки обробник більше не отримуватиме події від цього джерела.
12. **Мультиадресний делегат** може містити кілька методів у списку виклику. Вони виконуються послідовно в порядку підписки. Для подій це дозволяє кільком обробникам реагувати на ту саму подію; виняток одного обробника може перервати подальший виклик.
13. Делегат — типізований механізм виклику методів. Подія обмежує доступ до такого делегата: зовнішній код може підписуватися й відписуватися, але викликати подію може лише клас, у якому її оголошено.

### Ключові фрагменти для пояснення на захисті

- Делегат `CharacterArraySorter` дозволяє передати алгоритм як значення; обидва синтаксиси — анонімний метод і lambda — викликають той самий метод сортування.
- Черга перевіряє `IsFull` до `Enqueue`, тому не перевищує задану місткість. За спроби додавання при переповненні вона створює `QueueOverflowEventArgs` і генерує подію.
- Обробник має параметри `sender` та `eventArgs`: перший дає джерело, другий — відомості про конкретне переповнення.
